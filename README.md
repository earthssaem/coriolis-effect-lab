# 전향력 실험실

고등학교 **지구시스템** 과목의 "전향력" 개념을 수업 시간에 시연하기 위한 웹앱입니다.
세 단계 화면이 각각 한 가지 질문에 답하도록 구성되어 있습니다.

| 단계 | 질문 | 학생이 알아내야 할 한 가지 |
|---|---|---|
| 1 회전 원반 | 회전하는 원반 위에서 던진 공은 어떻게 보일까? | 회전하는 관찰자에게는 직선 운동이 휘어 보인다 |
| 2 지구에서의 운동 | 이 방향으로 출발하면 어느 쪽으로 휘어 보일까? | 북반구는 오른쪽, 남반구는 왼쪽, 적도는 수평 편향이 없다 |
| 3 전향 효과의 크기 | 전향 효과의 크기는 무엇에 따라 달라질까? | 속력이 빠르고 고위도일수록 크다 |

## 화면 구성

- **1 회전 원반**: 정지한 관찰자와 회전하는 관찰자가 본 공의 경로를 나란히 비교합니다. 던지기/처음으로, 시간 슬라이더, 회전 속도, 회전 방향만 조절합니다. 관찰한 뒤 "해석 보기"를 누르면 예상 경로와 경로 위 여러 지점의 전향력 화살표(항상 운동 방향에 수직, 방향이 계속 바뀜)가 나타납니다.
- **2 지구에서의 운동**: 출발 위도(북반구/적도/남반구)와 방향을 고르고, 왼쪽/휘지 않음/오른쪽을 예측한 뒤 실행합니다. 붉은 선이 실제로 보이는 경로, 파란 점선이 휘지 않았을 때의 경로입니다. 속력·추적 시간·배속·보는 위치·자전 속도 배율(3×, 10×)·다섯 위도 동시 발사는 "추가 설정 · 심화 탐구"에 접혀 있습니다.
- **3 전향 효과의 크기**: 위도 슬라이더와 속력 선택에 따라 a = 2vΩ|sinφ| 값과 위도별 그래프가 바뀝니다. 단위는 ×10⁻³ m/s²로 통일했습니다.

## 조작

- 상단 탭 또는 숫자 키 `1` `2` `3`으로 단계 전환
- 1단계: `Space` 던지기/일시정지, `R` 처음으로
- 2단계: `Enter` 실행, 마우스 드래그로 지구본 회전, 휠로 확대, 지구본 클릭으로 출발 위도 선택
- 3단계: 그래프를 클릭하면 그 위도로 이동

## 물리 모형

- 지구 자전 각속도 Ω = 7.2921×10⁻⁵ rad/s, 지구 반지름 6371 km
- 2단계는 지구에 고정된 좌표계에서 지표면을 따르는 수평 운동만 계산합니다.
  전향력에 의한 가속도는 (dv_E/dt, dv_N/dt) = (f·v_N, −f·v_E), f = 2Ωsinφ 이며 속력은 보존되고 방향만 바뀝니다.
  마찰·기압 경도력·곡률 항은 고려하지 않습니다.
- 3단계의 a는 단위 질량당 전향력의 크기입니다.

## 기술

순수 HTML/CSS/JavaScript(ES 모듈). 3D 렌더링은 [three.js](https://threejs.org) r160을 사용하며,
교실에서 인터넷이 불안정해도 동작하도록 `vendor/` 폴더에 포함해 두었습니다(MIT 라이선스, `vendor/LICENSE.three`).

로컬에서 확인할 때는 ES 모듈 로딩을 위해 간단한 정적 서버가 필요합니다.

```
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 열기
```
