# 전향력 실험실

고등학교 **지구시스템** 과목의 "전향력" 개념을 수업 시간에 시연하기 위한 웹앱입니다.
설치 없이 `index.html`을 브라우저로 열면 바로 동작하며, GitHub Pages로 배포할 수 있습니다.

## 구성

| 모듈 | 내용 | 교과서 대응 |
|---|---|---|
| ① 회전 원반 | 정지한 관찰자와 회전하는 관찰자가 본 공의 경로를 **나란히** 비교. 회전 속도·방향, 공의 속력, 시간 되감기, 전향력 화살표. **공 받기 도전**: 던지는 사람을 끌어 조준·던지기, 명중 판정과 점수, "정답 각도" 버튼 | 그림 Ⅱ-5 |
| ② 3D 지구본 | 지구본을 클릭해 발사 지점 선택. 실제 경로(붉은 선)와 전향력이 없을 때의 경로(파란 점선) 표시. **예측 퀴즈**(왼쪽/오른쪽/안 휨), "지구가 3배·10배 빨리 돈다면?" 자전 속도 배율, "교과서 그림 Ⅱ-6 재현" 버튼 | 그림 Ⅱ-6 |
| ③ 전향력의 크기 | 2vΩsinφ 계산기. 위도·속력 슬라이더, 위도에 따른 크기 그래프, 중력과의 비교, 옆으로 밀리는 거리. **도전 퀴즈**(방향·크기 비교·계산 문제 무작위 출제) | 본문 공식 |

## 조작

- 상단 탭 또는 숫자 키 `1` `2` `3`으로 모듈 전환
- 모듈 ①: `Space` 던지기/일시정지, `R` 처음으로
- 모듈 ②: `Enter` 발사, `Space` 일시정지, 마우스 드래그로 지구본 회전, 휠로 확대
- 모듈 ③: 그래프를 클릭하면 그 위도로 이동
- 상단 오른쪽 🔊 버튼으로 효과음 켜기/끄기

## 물리 모형

- 지구 자전 각속도 Ω = 7.2921×10⁻⁵ rad/s, 지구 반지름 6371 km
- 모듈 ②는 지구에 고정된 좌표계에서 수평 운동만을 계산합니다.
  전향력에 의한 가속도는 (dv_E/dt, dv_N/dt) = (f·v_N, −f·v_E), f = 2Ωsinφ 이며,
  속력은 보존되고 방향만 바뀝니다. 곡률·마찰·기압 경도력은 고려하지 않습니다.
- 모듈 ③의 "옆으로 밀리는 거리"는 전향력이 일정하다고 가정한 대략값(½at²)입니다.

## 배포 (GitHub Pages)

저장소 Settings → Pages → Source를 `main` 브랜치의 `/ (root)`로 지정하면
`https://<계정>.github.io/coriolis-effect-lab/` 에서 열립니다.

## 기술

순수 HTML/CSS/JavaScript(ES 모듈). 3D 렌더링은 [three.js](https://threejs.org) r160을 사용하며,
교실에서 인터넷이 불안정해도 동작하도록 `vendor/` 폴더에 포함해 두었습니다(MIT 라이선스, `vendor/LICENSE.three`).

로컬에서 확인할 때는 ES 모듈 로딩을 위해 간단한 정적 서버가 필요합니다.

```
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 열기
```
